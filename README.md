# 🐟 My Fish Tank

a Fish pet made using Vanilla Js, HTML Canvas, and **MATHSS**!

## controls

- **click above water** — drop food (the fish eats them and spawns hearts)
- **click in water** — spawn bubbles & ripples (tap close/fast to startle the fish)
- **click plants/rocks** — nudge foliage or shimmer stones
- **hover** — ripple the surface & drift motes

## run

open `index.html` in any browser.
