# 🐟 dithered fish jar

a tiny pixel aquarium in a glass jar, built with vanilla js and 4x4 bayer dithering on html5 canvas. no libraries, no sprites—just math.

## controls

- **click above water** — drop food pellets (the fish eats them and spawns hearts)
- **click in water** — spawn bubbles & ripples (tap close/fast to startle the fish)
- **click plants/rocks** — nudge foliage or shimmer stones
- **hover** — ripple the surface & drift motes

## run

open `index.html` in any browser.
